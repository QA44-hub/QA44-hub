  Я опытный тестировщик с 4+ лет стажа ручного и автоматизированного тестирования с международным сертификатом ISTQB. Участвовал в разнообразных проектах. Обладаю уверенными знаниями теории тестирования и активно применяю знания на практике. Имею солидный опыт тестирования WEB и Mobile приложений, а также интеграционного тестирования API. Работаю с логами и пишу SQL-запросы средней сложности. 
  
  Имею практические знания Python на начальном уровне. С помощью LLM пишу автотесты на Python, настраиваю запуск прогонов и отчётность по результатам.
  
  В работе активно использую LLM - для подготовки тестовых артефактов, разбора логов и рутинных задач, при этом всегда проверяю результат: для меня ИИ - инструмент, а не источник истины. Отдельно начинаю разбираться в тестировании самих LLM: как оценивать качество ответов там, где нет эталонного результата, и как проверять безопасность таких решений.
